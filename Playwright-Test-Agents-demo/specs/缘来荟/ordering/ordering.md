# 缘来荟商城 - 下单场景测试计划

- **模块名称**：ordering（下单流程）
- **产品**：缘来荟商城
- **测试类型**：端到端（E2E）用户下单流程测试

- **目标URL**：https://ecs.yto56test.com:4443/mall/#/login?type=1010

---

## 业务流程（主流程）

用户完成一次完整的下单操作需要经过以下步骤：

```
1. 搜索商品 → 输入"测试商品"搜索
2. 进入商品详情页 → 点击商品卡片
3. 点击"立即购买" → 进入规格选择
4. 选择规格 → 弹窗中选择规格组合，点击"确认购买"
5. 提交订单 → 在订单确认页点击"提交订单"
```

## 前置条件（共享 Fixture）

所有下单场景需要：
1. **已登录状态**：`yuanlaihuiLoggedIn` fixture 执行登录
2. **在商城首页**：已登录后停留在商城首页
3. **iframe 嵌套**：页面元素在 390x844 的 iframe 内，使用 `frameLocator('iframe')` 定位

---

## 技术要点（从 login/goods_search 场景继承）

- 页面嵌套在 iframe 中：`page.frameLocator('iframe')`
- 登录使用 fixtures：`await test.step('登录', async () => { await yuanlaihuiLoggedIn(); })`
- 规格弹窗需要等待：`await page.waitForSelector('.van-popup')`
- 订单提交后等待跳转：`await page.waitForTimeout(2000)` 后检查 URL 或成功提示
