# YLH 商城 - 加入购物车模块测试计划

## 一、模块概述

- **模块名称**：购物车模块 - 加入购物车
- **场景ID**：SC-CART-001 ~ SC-CART-004
- **测试目标**：验证用户可以将商品成功加入购物车，并在购物车页面中查看已添加的商品
- **涉及功能**：商品搜索 → 商品详情 → 加入购物车 → 购物车

## 三、主流程

### 3.1 基础操作流程

1. **登录**：通过 iframe 进行密码登录
2. **商品搜索**：使用关键词搜索商品，进入商品详情页
3. **加入购物车**：点击「加入购物车」按钮
4. **规格选择**：在规格选择弹窗中选中规格，点击「确认加入」
5. **验证购物车**：点击「购物车」入口，进入购物车页面，断言商品存在

### 3.2 核心元素定位

| 元素 | 选择器 |
|------|--------|
| 搜索框 | `input[placeholder="请输入商品名称或商品编码搜索"]` |
| 第一个商品卡片 | `.goods-item, .product-item, .goods-card, .van-card` |
| 加入购物车按钮 | `text=加入购物车` |
| 规格弹窗确认按钮 | `text=确认加入, text=确定` |
| 购物车入口 | `text=购物车, .van-tabbar-item__text` |
| 购物车商品列表 | `.cart-goods-list, .van-checkbox, .goods-list` |

## 四、测试场景

### SC-CART-001 - 正常加入购物车流程

**前置条件**：用户已登录

**测试步骤**：
1. 输入有效商品名称（如"自动化测试商品"）进行搜索
2. 等待搜索结果加载
3. 点击第一个商品卡片进入详情页
4. 点击「加入购物车」按钮
5. 在规格弹窗中选择第一个可用规格
6. 点击「确认加入」按钮
7. 点击底部「购物车」标签
8. 等待购物车页面加载

**预期结果**：
- 商品成功加入购物车
- 购物车页面显示已添加的商品
- 商品名称与搜索商品一致

**优先级**：P0

---

### SC-CART-002 - 规格弹窗取消操作

**前置条件**：用户已登录，已进入商品详情页

**测试步骤**：
1. 点击「加入购物车」按钮
2. 在规格弹窗中点击「取消」或关闭弹窗
3. 不选择规格

**预期结果**：
- 弹窗关闭
- 商品未加入购物车

**优先级**：P1

---

### SC-CART-003 - 快速连续点击确认加入

**前置条件**：用户已登录

**测试步骤**：
1. 进入商品详情页
2. 点击「加入购物车」按钮，打开规格弹窗
3. 选择规格后，快速连续点击「确认加入」按钮多次（3-5次）
4. 点击底部「购物车」标签

**预期结果**：
- 系统只加入一次（或给出重复提示）
- 购物车中商品数量正确（应为1件）

**优先级**：P1

---

### SC-CART-004 - 选择添加的商品数量

**前置条件**：用户已登录，已进入商品详情页

**测试步骤**：
1. 点击「加入购物车」按钮
2. 在规格弹窗中调整商品数量（如 +2 或直接输入数量）
3. 选择规格后点击「确认加入」
4. 点击底部「购物车」标签
5. 查看已添加商品的数量

**预期结果**：
- 购物车中显示的商品数量与选择的一致
- 商品总价正确（数量 × 单价）

**优先级**：P0

## 五、边界场景

| 场景 | 描述 |
|------|------|
| 网络延迟 | 加入购物车后等待较长验证数据保存 |
| 商品无规格 | 商品本身无SKU规格时的处理 |
| 规格仅一个 | 只有一个规格时的自动选中 |
| 购物车已满 | 验证最大商品数量限制（如果有） |
| 数量边界 | 数量为0或超过最大限制时的处理 |

## 八、执行要求

1. 所有测试使用 `loginAsNormalUser` 进行登录
2. 每个测试用例独立执行，不依赖其他测试用例的状态
3. 测试完成后不需要清理购物车（独立测试环境）
4. 使用 `frameLocator('iframe')` 获取iframe上下文
5. 添加适当的等待时间确保页面加载完成
